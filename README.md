## 🎨 Animation Features

### 1. Particle Network Background
- Canvas-based particle system with 50+ interactive particles
- Mouse interaction: particles react to cursor movement
- Connecting lines create dynamic network visualization
- Optimized with RequestAnimationFrame for 60fps performance

### 2. Advanced Typewriter Effect
- Character-by-character typing with variable speed
- Realistic typing rhythm (80-120ms per character)
- Blinking cursor during and after typing
- Auto-starts on page load

### 3. 3D Card Tilt
- Perspective-based tilting on mouse movement
- Dynamic shadows that follow tilt direction
- Smooth cubic-bezier transitions
- Applied to all value cards, metrics, and case studies

### 4. Animated Gradient
- Slowly shifting 4-color gradient in hero section
- 15-second loop for subtle movement
- Navy → Light Blue → Dark → Navy progression

## 🚀 Quick Start

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RobinCHoffpauir/RobinCHoffpauir.github.io.git
   cd RobinCHoffpauir.github.io
   ```

2. **Serve locally:**
   ```bash
   # Using Python 3
   python3 -m http.server 8000

   # OR using Node.js
   npx http-server -p 8000
   ```

3. **Open in browser:**
   ```
   http://localhost:8000
   ```

### Deployment

The site auto-deploys to GitHub Pages on push to `main`:
- **Production URL:** https://robinchoffpauir.github.io
- **Custom Domain:** (configured via CNAME)
