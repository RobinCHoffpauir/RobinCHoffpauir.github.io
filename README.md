# 🌐 Robin C. Hoffpauir — Portfolio & Professional Hub

Welcome to the source code for my personal portfolio, hosted at **[robinchoffpauir.github.io](https://robinchoffpauir.github.io)**.  
This site showcases my work as a **SaaS & GTM Leader** specializing in **Partnerships, Cloud, and AI** — built entirely with lightweight, responsive HTML/CSS/JS and deployed via GitHub Pages.

---

## 🚀 Overview

This portfolio is designed as a **central professional hub** — blending my résumé, case studies, thought leadership, and an expanding library of insights on go-to-market strategy and cloud ecosystems.

### ✨ Key Highlights
- **Dynamic Navigation:** Fixed top bar with dropdown menu for *Writing ▾ → Thought Leadership / Blog*
- **Dark/Light Mode Toggle:** Persistent theme toggle with smooth transitions  
- **Performance-First Design:** Minimal dependencies, fast load, mobile-optimized  
- **Modular Architecture:** Each page functions independently but shares a unified style guide and layout  
- **Scalable Content Model:** Supports blog posts, visual data dashboards, and embedded media (LinkedIn, Spotify, Apple Podcasts)
